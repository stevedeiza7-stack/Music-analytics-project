# Data Source Register

This document records every external data source investigated,
selected, rejected, or used in the Music Analytics Project.

## Purpose

To maintain transparent data provenance and document the reasoning
behind source selection.

## Source Evaluation Criteria

Each candidate source will be evaluated for:

1. Provenance
2. Relevance
3. Geographic coverage
4. Time coverage
5. Variable availability
6. Data quality
7. Reliability
8. Reproducibility
9. Licensing and usage rights
10. Suitability for the research question
